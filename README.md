# 咔嗒咔嗒积木医院

一个给亲子角色扮演使用的磁力片积木医院。家长在网页中扮演医生，完成挂号、检查动画、病历保存、回访和打印；小朋友使用乐高、磁力片和 A4 操作纸进行动手游戏。

完整的产品边界、科室模板、A4 规范和验收清单见 [游戏设计规范](docs/GAME_DESIGN_SPEC.md)。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可。开发模式会同时启动网页与本地 SQLite 服务。

构建后运行：

```bash
npm run build
npm start
```

然后打开 `http://127.0.0.1:8787`。

## 主要功能

- 6 秒分阶段动态扫描
- 六层剖面式虚拟医院大楼：下一站提示、患者电梯、楼层定位、完成盖章和自由探索
- 多患者候诊区：每个积木小人拥有独立病历
- 挂号时拍照或上传照片，并选择彩虹、太空、恐龙、城堡病历背景
- 8 个科室的一键自动检查动画与趣味报告
- 分诊根据症状生成 2～5 站路线，不要求一次完成全部科室
- 动态积木小人 X 光影像、检查部位与症状选择
- 10 种能量 × 10 种故障 × 10 种诱因，共 1000 种趣味病情
- 6 类治疗各有 10 种选项，超过 1,000,000 种治疗组合
- 病因关联的影像指标、六步快乐处方、护理建议、复查任务和勇气贴纸
- 完整就诊自动归档，可查看每次科室检查、分数和贴纸
- 出院后自动安排第 1、3、7 个游戏日回访，家长记录纸上活动和恢复情况
- 患者、就诊、科室结果、回访和奖励由 SQLite 持久保存
- 新科室各有至少 1000 种趣味病情组合，检查发现与快乐处方会完整归档
- 一页 A4 单科报告与全院出院纪念证书
- 按科室打印的 A4 操作纸，以及根据今日路线自动生成的打印包
- 一页就诊单、处方打卡表、回访记录、手绘病历和两张 A4 拼接医院大楼
- 手机、平板和电脑自适应

## 数据保存在哪里

- SQLite 数据库：`data/clinic.db`
- 患者照片：`data/photos/`
- 浏览器只保存当前选中的患者编号；旧版浏览器病历会在第一次启动时自动迁移进 SQLite。

数据只保存在运行项目的这台电脑上，不会自动上传网络。备份时请先停止程序，再完整复制 `data` 文件夹；恢复时覆盖回原位置即可。

## 常用命令

```bash
npm run dev          # 同时启动网页和 SQLite 服务
npm run dev:web      # 只启动 Vite 网页
npm run dev:server   # 只启动本地数据服务
npm run build        # 生成正式网页
npm start            # 用 8787 端口运行正式网页和数据服务
```

> 本项目仅供亲子角色扮演游戏使用，不提供真实医疗诊断。
