# 咔嗒咔嗒积木医院：游戏设计规范

## 1. 产品意图

本项目是一套亲子角色扮演工具，不是一款让儿童独自操作屏幕的小游戏合集。

网页模拟家长扮演医生时使用的医院电脑，负责挂号、路线引导、检查动画、病历保存、回访提醒和打印。真正面向儿童的游戏发生在父母陪伴、乐高小人、磁力片和打印出来的 A4 纸上。

一句话原则：**电脑负责导演和记录，父母负责讲故事，孩子负责动手玩。**

## 2. 角色与职责

| 参与者 | 主要职责 | 不承担的职责 |
| --- | --- | --- |
| 网页 | 展示医院流程、播放检查动画、生成趣味报告、保存资料、管理回访、打印纸张 | 不考验儿童的点击速度、记忆、排序或屏幕操作能力 |
| 父母 | 操作网页、扮演医生、朗读提示、陪伴操作、记录观察结果 | 不替孩子完成纸上的创造内容 |
| 儿童 | 操作乐高与磁力片、画画、涂色、连线、贴纸、在成人协助下剪贴 | 不需要独自阅读大段文字或完成网页关卡 |
| A4 纸 | 承载科室活动、处方执行、回访记录、医院地图与自由创作 | 不模拟真实诊疗，不提供真实用药或医学建议 |

## 3. 网页与纸张的边界

### 3.1 网页允许的交互

- 家长填写姓名、年龄、症状和照片。
- 家长选择患者、科室、检查部位与打印内容。
- 家长点击一次“开始检查”，网页自动播放 4～8 秒动画。
- 家长保存检查报告、回访记录和病历。
- 家长打印单科操作纸、今日路线包、处方、病历和医院大楼。
- 儿童可以观看动画或收听语音，但观看不是完成流程的条件。

### 3.2 网页禁止的交互

- 重复点击固定次数才能完成检查。
- 寻找隐藏物、拖放、排序、反应速度、限时操作或答题通关。
- 因为点错、点慢或看不懂文字而阻塞就诊。
- 用屏幕游戏成绩决定病情、处方或能否出院。
- 把可以在纸上完成的涂色、连线、剪贴重新做成网页小游戏。

### 3.3 纸张优先的儿童互动

- 画画、涂色、描线、圈选、迷宫、找不同。
- 在成人协助下沿虚线剪纸、粘贴零件和制作小道具。
- 移动乐高小人、磁力片和纸质电梯卡。
- 用贴纸、印章或画星星记录完成次数。
- 与父母进行医生、护士、患者和药剂师角色扮演。

## 4. 标准就诊流程

1. 家长给乐高患者挂号并上传照片。
2. 分诊系统根据症状生成 2～5 个科室的路线。
3. 医院大楼突出显示下一站，家长带孩子移动实体小人。
4. 进入科室后，家长把实体小人放进对应颜色的磁力片房间。
5. 家长点击一次“开始检查”，网页自动播放检查动画。
6. 网页生成趣味病情、发现、快乐处方和科室操作纸。
7. 家长打印操作纸，儿童离开屏幕进行画、涂、剪、贴和角色扮演。
8. 家长保存报告并返回医院大楼。
9. 完成路线后归档病历、打印出院证书并安排回访。

纸上活动是否完成可以由家长记录，但不得阻塞报告保存或出院。

## 5. 科室模板

每个科室网页必须使用统一结构：

1. 科室名称、颜色和实体搭建提示。
2. 一个明确的“开始检查”按钮。
3. 自动、可跳过、支持减少动画偏好的检查动画。
4. 图形优先的检查结果，包含病情、发现、快乐处方和贴纸。
5. “打印本次操作纸”和“保存结果，返回大楼”两个主要动作。

每个科室必须提供一张独立 A4 操作纸：

| 科室 | 自动动画 | 纸上活动 |
| --- | --- | --- |
| X 光室 | 扫描骨架与能量核心 | 描画骨架、圈出检查位置、设计骨骼盔甲 |
| 心脏科 | 心电线与勇气核心跳动 | 描心电线、涂亮 8 颗心、画勇气核心 |
| 牙科 | 扫描牙齿并显示糖果虫位置 | 找虫、圈牙齿、涂色、剪下糖果虫和纸牙刷 |
| 彩虹药房 | 自动展示三色能量处方 | 按处方涂色、剪下能量瓶、贴进药袋 |
| 骨科 | 骨骼蓝图依次亮起 | 剪贴手脚与身体、拼骨架、画保护盔甲 |
| 积木外科 | 清洁、检查、补丁动画 | 圈擦伤、设计创可贴、剪贴彩色补丁 |
| 能量内科 | 四个身体仪表自动扫描 | 给温度、睡眠、呼吸与快乐仪表涂色 |
| 肠胃科 | 食物列车通过肚肚车站 | 走迷宫、画路线、剪贴食物乘客 |
| 耳鼻喉科 | 声音在耳、鼻、喉三个通道中自动行进 | 随机声音宽迷宫、避开灰尘云、剪纸检查工具 |
| 眼科 | 左右眼焦点、眨眼雨刷与颜色自动校准 | 图形视力表、追踪连线、找相同、设计纸眼镜 |
| 呼吸科 | 空气泡泡依次进入左右肺 | 吹棉球宽赛道、描泡泡、画新鲜空气云 |
| 皮肤科 | 外壳保护层与想象斑点自动扫描 | 找不同、花纹配对、设计保护服、剪贴补丁 |
| 超声波室 | 回声圆圈自动扩散并标记隐藏图形 | 描回声圈、寻找宝藏、编回声故事 |
| 能量化验室 | 红黄蓝想象样本自动排序和计数 | 涂纸试管、连接相同图形、给样本起名 |
| 康复训练室 | 自动选择动作主题并观察平衡能量 | 剪动作卡、让乐高摆姿势、走纸上脚印 |
| 营养工作室 | 自动选择彩虹餐盘的颜色组合 | 剪贴食物、按颜色分类、设计能量餐盘 |
| 心情加油站 | 表情、天气与陪伴能量自动记录 | 选天气卡、亲子讲感受、画心情故事 |

正式科室共 12 个，辅助房间共 5 个。辅助房间也保存检查结果并提供独立 A4，但必须明确它们属于想象检查、恢复或表达活动，不模拟真实化验、饮食处方和心理诊断。

### 5.1 楼层与路线

- 1F：挂号台、病历室、打印工坊。
- 2F：X 光室、骨科、积木外科、康复训练室。
- 3F：心脏科、呼吸科、超声波室、能量化验室。
- 4F：能量内科、肠胃科、营养工作室、彩虹药房。
- 5F：耳鼻喉科、眼科、牙科、皮肤科。
- 6F：出院中心、回访中心、心情加油站。

分诊路线最多 5 站，只突出下一站。辅助房间通过相关症状或前置科室进入，不要求儿童浏览全部房间。

### 5.2 纸面活动模板库

- 宽通道迷宫和收集型迷宫，可直接移动乐高小人。
- 图形追踪、连点成图、找相同与找不同。
- 涂色、图形配对、颜色分类和纸上仪表。
- 剪贴修复、拼装零件、纸制检查工具和角色牌。
- 动作卡、表情天气卡、亲子故事卡和医生记录区。
- 吹棉球等实体玩法必须标注成人看护，不使用网页成绩决定结果。

## 6. A4 设计规范

- 每张科室操作纸严格控制在一张 A4 纵向纸内。
- 安全边距不小于 8 mm；重要内容距离裁切边不小于 10 mm。
- 儿童操作说明尽量控制在 3 步以内，每步同时提供图标和短句。
- 主要操作区域优先占据页面一半以上。
- 需要书写的文字不小于 11 pt；儿童标题建议 16～24 pt。
- 剪切线使用清晰虚线，并显示“请大人帮忙使用剪刀”。
- 需要剪下的零件之间保留足够空隙，不安排在纸张边缘。
- 黑白打印时仍应能通过轮廓、纹理和编号区分内容，不能只依赖颜色。
- 每张纸包含患者姓名、日期、科室、病历编号和游戏用途声明。
- 同一份病历重复打印时，随机内容必须保持一致。

## 7. 数据与可重印性

每份科室结果应保存：

- 科室、病情、检查发现、快乐处方、贴纸和报告分数。
- 操作纸模板编号与版本。
- 随机种子，用于稳定复现虫子位置、颜色处方和图纸变化。
- 生成时间，以及可选的打印时间和纸上活动完成时间。

网页不保存重复点击次数、关卡步数或数字星星进度。回访只保存家长观察到的心情、能量、备注和完成时间。

## 8. 回访规范

- 第 1 天：儿童在纸上圈选心情，家长录入观察结果。
- 第 3 天：儿童完成一项纸上或实体恢复任务，家长记录过程。
- 第 7 天：儿童涂亮康复星，家长记录最终状态。
- 网页可以提醒、打印和保存，但不设置数字关卡。
- 没有打印机时，家长仍可直接记录并完成回访。

## 9. 安全与语言

- 所有病情、治疗和药品均使用明确的想象性、积木化表达。
- 不提供真实诊断、真实剂量、真实用药或替代医疗建议。
- 外科不出现血液、伤口细节或令人害怕的手术画面。
- 使用剪刀的活动必须要求成人协助。
- 棉球等小物件必须由成人看护，不适合会把小物放入口中的儿童。
- 真实出现呼吸困难、持续疼痛或明显不适时，应立即停止游戏并由家长寻求真实医疗帮助。
- 真实身体不舒服时，页面和纸张都提醒儿童告诉家长并咨询医生。
- 不用“失败”“答错”“不合格”等惩罚性语言。

## 10. 功能验收清单

- [ ] 任一科室最多只需一次点击即可启动检查。
- [ ] 检查动画结束后自动生成报告，不需要儿童通关。
- [ ] 每个科室都有一张独立、可重印的 A4 操作纸。
- [ ] 今日路线包只打印本次需要的科室。
- [ ] 没有打印机时仍可完成整个就诊流程。
- [ ] 重印同一病历时随机内容保持一致。
- [ ] 回访页面明确标注为“家长记录”。
- [ ] 出院条件只取决于报告是否保存，不取决于儿童表现。
- [ ] 所有动画支持 `prefers-reduced-motion`。
- [ ] 所有打印页经过 PDF 渲染检查，没有裁切、重叠和溢出。
